# Flores_GM

## 📋 Descripción
Proyecto de gestión y análisis Flores_GM.

## 🏗️ Estructura del Repositorio
- `docs/`: Documentación del proyecto dividida por fases (Discovery, Engineering, Modeling, Delivery).
- `src/`: Código fuente de la aplicación y pipelines.
- `data/`: Datos del proyecto (Bronze, Silver, Gold). *Ignorado por Git*.
- `models/`: Modelos entrenados y serializados. *Ignorado por Git*.
- `notebooks/`: Jupyter Notebooks para experimentación.
- `tests/`: Pruebas unitarias, de integración y de datos.
- `infra/`: Configuraciones de infraestructura y CI/CD.

## 🚀 Metodología
Este proyecto sigue la metodología **SpecDD** (Specification-Driven Development) y está organizado en 4 fases principales:
1. **Discovery**: Definición de negocio y factibilidad técnica.
2. **Engineering**: Construcción del pipeline de datos certificado.
3. **Modeling**: Entrenamiento y validación del modelo.
4. **Delivery**: Despliegue y puesta en producción.
