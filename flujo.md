# Flujo de trabajo:

## Aranque del proyecto:

1. Crear el archivo GEMINI.md general.
2. Crear la carpeta docs/references y crear el archivo principles.md.
3. Crear la carpeta .gemini/agents y .gemini/skills.
4. Copiar en .gemini/agents y .gemini/skills todas los agentes y habilidades del proyecto.
5. Crear la carpeta docs/methodology y pegar el archivo process.md con la metodologia de trabajo.
6. Crear o copiar el archivo agents.md en docs/references.
7. Crear la carpeta docs/design-system con la informacion base para el front de la aplicacion.
8. Crear el cerebro del proyecto en notebooklm, utilizando la habilidad
9. Construir la estructura inicial del proyecto con ai-repository-manager.
10. Realizar el primer commit al repositorio en github.
11. Construir el backlog de la primera fase basado en la metodologia utilizando el agente especializado ai-backlog-manager, 
12. Crear el workflow de githbub action ci.yml|
13. Cerrar la primera sesion del proyecto utilizando el agente especializado.
14. Realizar el enlace con git y github utilizando el agente.



## Fase 1 Discovery: Inicio formal del proyeecto:
1. Siguiendo el backlog de la fase 1 y ejecutando la primera tarea que debe ser la construcion del 
config.md
2. Creacion del archivo brd.md con el agente especializado.
3. Creacion del archivo behavior.md con el agente especializado.
4. Analisis de factibilidad de la implementacion de los requerimientos utilizando el agente especialista.
5. Construccion del mockup de prototipado.
6. Construccion del archivo [[SAD]].md  - Creacion del archivo sources.md basado en el stack de tecnologia seleccionado.
7. Construccion del archivo SpecDD.md
8. Construccion del archivo contract.md
9. Actuualizacion del backlog con las tareas de la fase 2.
10. Cierre de la sesion.
11. Subir al repositorio en github.
